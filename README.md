# Restaurant POS Prototype

A Flutter-based Restaurant Management System (POS) prototype designed for both mobile and tablet devices.

## Features
- **Responsive Design**: Adapts layout automatically for Mobile (Phone) and Tablet screen sizes.
- **Menu Management**: Filter items by category.
- **Cart System**: Add, remove, and update quantities of items.
- **Mock Data**: Pre-populated with sample restaurant items.
- **Theming**: Modern UI using Material 3 and custom design system.

## Project Structure
- `lib/models/`: Data models for Menu items and Orders.
- `lib/providers/`: State management using Provider.
- `lib/screens/`: Responsive dashboard implementations.
- `lib/widgets/`: Reusable UI components.
- `lib/theme/`: Global styling and themes.

## Getting Started
1. Ensure Flutter is installed on your machine.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to launch the app on your preferred device.

## Technologies Used
- Flutter SDK
- Provider (State Management)
- Google Fonts (Typography)
- Intl (Currency Formatting)
